# TaskFlow Dashboard

A modern project management dashboard built with React, TypeScript, and Tailwind CSS.

## Overview

TaskFlow Dashboard is a comprehensive project management application that helps you organize tasks, track time, manage teams, and visualize project progress. The intuitive interface makes it easy to stay on top of deadlines and collaborate effectively.

## Features

- **Project Management**: Create, edit, and organize projects with customizable details
- **Task Tracking**: Break down projects into manageable tasks with priorities and deadlines
- **Time Logging**: Track time spent on tasks with an integrated time tracking system
- **Team Collaboration**: Manage team members and assign roles/permissions
- **Reporting**: Generate insightful reports on project progress and resource allocation
- **Calendar View**: Visualize deadlines and milestones in an interactive calendar
- **User Profiles**: Personalize your experience with custom user profiles

## Technology Stack

This project is built with:

- **React** - Frontend library
- **TypeScript** - Type-safe JavaScript
- **Tailwind CSS** - Utility-first CSS framework
- **shadcn/ui** - UI component system
- **React Router** - Routing and navigation
- **React Query** - Data fetching and state management
- **Vite** - Build tool and development server

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn package manager

### Installation

```sh
# Clone the repository
git clone https://github.com/your-username/task-flow-dashboard.git

# Navigate to the project directory
cd task-flow-dashboard

# Install dependencies
npm install

# Start the development server
npm run dev
```

The application will be available at `http://localhost:5173`
